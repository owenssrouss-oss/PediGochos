📋 Términos & Verificación

1. Verificación Telefónica Antifraude

Para proteger a nuestros repartidores y establecimientos afiliados, todo pedido está sujeto a verificación telefónica. El comercio podrá llamarle al número provisto para confirmar la orden antes de comenzar la preparación.

2. Compromiso de Recepción y Pago

Al enviar esta solicitud, el cliente asume el compromiso formal de recibir el pedido y realizar el pago total indicado (en efectivo o mediante la plataforma, según corresponda).

3. Política de Privacidad de Datos

Sus datos de contacto y dirección se compartirán únicamente con el comercio y el repartidor para completar la entrega física de esta orden específica.
